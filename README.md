# 503 — тренажёр System Design

Браузерная игра: нагрузка растёт в реальном времени, а ты достраиваешь архитектуру — балансировщик, CDN, кэш, реплики, шарды, очередь, — пока система не легла.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm run build` | Статическая сборка в `out/` — хостится на любом статик-сервере |
| `npm test` | Тесты баланса: каждый уровень должен проходиться |
| `npm run lint` / `npm run typecheck` | ESLint и TypeScript |

## Стек

Next.js (App Router, статический экспорт) · TypeScript · Tailwind CSS v4 · React Flow (`@xyflow/react`) для схемы · Motion для анимаций интерфейса · Zustand для прогресса · Vitest.

## Как устроено

- `src/lib/sim/` — симуляция нагрузки, чистая логика без React: `engine.ts` (шаг симуляции, покупки, диагностика узких мест, оценка ёмкости), `levels.ts` (уровни и кривые нагрузки), `balance.test.ts`.
- `src/lib/view.ts` — неизменяемый снимок состояния для интерфейса. Симуляция мутабельна и крутится в `requestAnimationFrame`; React получает снимки ~9 раз в секунду.
- `src/lib/layout.ts` — раскладка узлов и связей схемы.
- `src/lib/particles.ts` — частицы запросов на canvas. Холст лежит внутри вьюпорта React Flow, поэтому зумится и двигается вместе со схемой.
- `src/components/flow/` — граф: узлы как React-компоненты, связи, слой частиц.
- `src/components/` — экран игры, HUD, панель действий, график нагрузки, диалоги, меню.

## Как добавить уровень

Добавь объект в `LEVELS` в `src/lib/sim/levels.ts`: доли статики и записи, кривую нагрузки, стартовый бюджет, доступные компоненты. Затем допиши его id в `balance.test.ts`, чтобы проверять проходимость.
